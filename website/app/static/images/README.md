The Modules wordmark identifies this application: its white variant appears on the dark navigation surface, its color variant on the mobile header and login card, and its icon is the favicon. The main MISP wordmark identifies the parent project in the navigation footer and login card. All files are served locally, retain their original colors and proportions, and contain vector outlines rather than external fonts. No artwork was recolored, redrawn, or cropped.
